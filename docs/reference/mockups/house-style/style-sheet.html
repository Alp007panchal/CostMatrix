Rules for every screen

Sidebar: 15 items in six groups, numbered in the order work flows; counts only where a person must act (orange when overdue). Admin pages live inside Settings as vertical tabs; rates, kit groups, price lists and import live inside Library set-up the same way. A page shows at most: four KPI tiles, one exception bar, two sections. Lists open with filters on one line and show five to eight columns, never more; details open beside the list, not in a new page. Long screens use vertical tabs (costing panels, settings), short ones use tabs under the title. Everything switched off in Features simply does not appear.
