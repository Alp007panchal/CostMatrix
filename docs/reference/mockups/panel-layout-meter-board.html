How capacity is worked out
Each plate type has a usable width and a rule: side by side — devices fill the width by their own width (MCBs by 18 mm modules, contactors and meters by their real width plus clearance). Plates stack down the box's usable height. The box is chosen from the catalogue as the smallest whose usable height and width hold all the plates.
