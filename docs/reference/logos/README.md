# Logo files

Put the images that appear on the quotation here:

- `header-logo.png` — the company logo printed at the top of every page. PNG or SVG, at least 600 px wide so it stays sharp in print.
- One file per footer mark, e.g. `siemens.png`, `cs-electric.png`, `kebs.png`, `iso-9001.png`. These print as a strip at the bottom of every page.

Names do not matter to the app; they are uploaded through the company settings screen and
stored in Supabase. This folder is the source copy so the design can be checked against the
real marks.
